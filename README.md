A one-line entry for the make.fun competition "The Battery's Last Text to Its Charger": the phone battery's final, slightly spiteful text message to the charger it waited for all day. The program (`main.py`, stdlib-only) writes that single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
